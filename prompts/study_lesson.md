# 기초 강의 작성 지시문 (Claude Code 가 매주 따라 할 것)

> 사용법: Claude Code 에게 **"prompts/study_lesson.md 대로 다음 강의 써줘"** 라고 말한다.
> 예약 작업이 매주 목요일에 자동으로 실행한다.

## 목적
반도체 공정·장비 직무 면접에서 "기본기"로 묻는 내용을 주 1강씩 정리한다.
최신 동향(주간 다이제스트)과 짝을 이루는 **교과서형 학습 노트**다.
독자는 본인(반도체 전공 대학원생, CNT 냉음극 멀티빔 전자원 연구). 학부 전공 수준에서 시작해 면접 답변 수준까지 끌어올린다.

## 순서
1. (원격 저장소 연결 후) `git pull`.
2. `site/data/curriculum.yaml` (커리큘럼 — 블로그 강의 목차 페이지도 이 파일로 만든다) 에서 **아직 글 폴더가 없는** 가장 작은 번호의 강의를 고른다.
   글 폴더: `site/content/study/<번호 두 자리>-<slug>/index.md`. 모든 강의가 끝났으면 멈추고 보고한다.
3. 그 강의의 `points` 를 모두 다룬다. 빠뜨린 게 있으면 "다음 강의에서 다룸" 등으로 명시한다.
4. 그림 준비 (아래 그림 규칙).
5. 아래 형식으로 글을 쓴다. 참고 예시: `site/content/study/01-semiconductor-basics/index.md`
6. `hugo --source site --quiet` 로 빌드 확인.
7. 커밋·push. 커밋 메시지: `study: <번호>강 <제목>` + 빈 줄 + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
   push 가 실패하면 커밋은 남기고 이유를 보고한다 (강제 push 금지).
8. 무엇을 썼는지 3줄 요약 + 블로그 주소를 보고한다.

## 저작권·정확성
- 특정 교재(예: 시중 면접 대비서)의 문장·도표·문제를 옮기지 않는다. 일반 교과서 수준 지식을 **내 말로** 정리한다.
- 식·상수·대표값은 교과서에 널리 실린 것만 쓴다 (예: Si 밴드갭 약 1.12 eV, 300 K). 확실하지 않으면 범위나 정성적 표현으로.
- 업계 현황(특정 회사의 양산 시점 등)은 이 블로그의 주간 다이제스트나 공개 출처에 근거가 있을 때만 쓰고 링크한다.

## 글 형식 (Hugo markdown)

```markdown
---
title: "<번호>강. <제목>"
date: <작성일 YYYY-MM-DD>
weight: <번호>
part: <이론|후공정|장비>
tags: [<curriculum keywords + 주제 태그>]
summary: "<한 문장 요약>"
cover: <대표 그림 파일명>
---

> **이번 강의 목표** — 이 강의를 마치면 할 수 있어야 하는 것 3~4개 (예: "공핍층이 생기는 이유를 밴드 그림으로 설명할 수 있다")

## 1. <첫 주제>
설명 → 그림 → 핵심 식(있으면) → 공정/장비와의 연결.
...

## N. 공정·장비 현장과의 연결
이 기초가 실제 공정·장비 업무에서 어디에 쓰이는지 3~5개.

## 면접 질문
<details> 로 5~7개. 기본 정의 2개, 원리 설명 2개, 트레이드오프·응용 1~2개, 내 연구 연결 1개(억지면 생략).
각 답변은 "답변 뼈대" 3~5줄.

## 한 장 요약
핵심을 표 또는 6~8줄 목록으로 (시험 전날 복습용).

## 최신 동향과 연결
주간 다이제스트(`site/content/posts/`) 중 이 강의와 관련된 글(커리큘럼 keywords 와 태그가 겹치는 글)이 있으면 링크하고 한 줄로 연결. 없으면 이 섹션 생략.

## 더 공부할 거리
공개 자료만: 위키백과 문서, 대학 공개 강의(MIT OCW 등), 교과서 이름(예: Sze, *Physics of Semiconductor Devices*). 링크가 확실한 것만.
```

- 분량: 6,000~10,000자. 그림 3~5개.
- 굵게 표시 주의: 닫는 `**` 앞이 괄호·마침표이고 바로 뒤가 한글이면 굵게가 깨진다. `**공핍층**(depletion)은` 처럼 괄호를 밖으로.
- 수식은 일반 텍스트로 (예: `n·p = nᵢ²`). LaTeX 렌더러는 없다.

## 그림 규칙
주간 다이제스트와 같다 (`prompts/weekly_digest.md` 의 "그림 규칙"):
1. 자유 라이선스 원본 (Wikimedia Commons, CC BY 오픈액세스 논문) → `figures_sources.json` 기록 + 캡션에 작가·라이선스
2. 이용 조건이 허용하는 기업 보도자료 이미지
3. 없으면 직접 그린 SVG 개념도 (흰 배경, 한글 글꼴, width/height 속성)
- 교재·언론사 그림은 쓰지 않는다.
- 넣는 법: `{{</* fig src="파일" caption="설명" source="출처" source_url="…" license="…" license_url="…" */>}}`
